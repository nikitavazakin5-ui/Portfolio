NIKITA® PORTFOLIO

Files:
- index.html : portfolio home
- style.css  : portfolio styles and visual effects
- script.js  : GSAP scroll reveals, pointer tilt, Three.js hero animation
- projects/burger.html : Burger Lab concept project page
- projects/burger.css  : Burger Lab page styles

How to run:
1. Extract this folder.
2. Open index.html in VS Code.
3. Install/enable Live Server (recommended) and click "Go Live".
4. Three.js and GSAP load from CDNs, so internet connection is needed for those scripts and Google Fonts.
